# Robot joint state in workcell project ZIPs

Date: 2026-11-13. Project ZIPs now optionally contain `robot-state.json`, referenced by `project.json` as `"robotState":"robot-state.json"`. The payload is `{ "jointNames": [...], "positions": [...] }`: one finite position in radians or metres for each independent nonfixed, nonmimic URDF joint. The project version remains 1. Existing ZIPs without the entry still open, using the URDF's home joint values.

The browser saves the currently displayed joint values alongside the SDF snapshot's model world poses and attachment records. On open, it unpacks and validates the joint-state shape, validates names and direct/mimic-derived limits against the archived URDF, and validates the world attachment graph **before** replacing the current workcell. It then loads the SDF and URDF, applies the saved independent joint values, updates the robot's world transforms, and only then reattaches scene objects with world-pose preservation. This order is necessary for a workpiece attached to a moving robot TCP: restoring joints after attachment would move the workpiece away from its saved world pose.

The Chromium Worker fixture [`notes/scripts/check_weld_join.cjs`](scripts/check_weld_join.cjs) saves the two-plate welded assembly midway through robot carry, after both `extension_plate → model/workpiece` and `workpiece → robot/seam_cartesian/link/tcp_link` are active. At save and reopen, the joint values are identically `slide_x=0.4750045128714498` m and `slide_y=0.0000016483502505525` m; the parent remains at (0.1750101381, -0.0699916021, -0.075) m and the child at (0.5750101381, -0.0699916021, -0.075) m. A second ZIP after release also restores its final joint values and both plate poses. [Archived JSON](artifacts/weld_join.json) contains the full before/after evidence.

The probe injects an otherwise valid ZIP whose `slide_x=999` m exceeds the URDF upper limit 0.8 m. Import reports `Project robot state for slide_x is outside [0, 0.8].` and the current robot q, scene poses, attachments, and program remain unchanged. It also removes the new entry and manifest pointer to emulate an old ZIP: the workcell opens at home q while retaining the archived object world poses and attachments.

`tests/project-bundle.test.cjs` checks new and old ZIP formats and malformed state entries. `tests/project-robot-state.test.cjs` checks name coverage, direct limits, and mimic-derived limits. `tests/weld-join-fixture.test.cjs` checks the browser round trips and failed import. The ZIP restores configuration and scene state; it does not resume program playback time, joint velocities, accelerations, or controller execution.
