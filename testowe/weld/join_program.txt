# Draw a kinematic seam on workpiece, join its touching extension, then carry both.
# JOIN is a scene-parenting event; it does not simulate melting or bond strength.
ROBOT seam_cartesian
TOOL tcp_link
POSE seam_start world 0.15 0 0 Q 0 0 0 1
POSE via world 0.35 0.14 0 Q 0 0 0 1
POSE arc_end world 0.55 0 0 Q 0 0 0 1
POSE seam_end world 0.65 0.12 0 Q 0 0 0 1
POSE carry_end world 0.30 -0.12 0 Q 0 0 0 1
MOVEJ seam_start
WELD ON workpiece
MOVEC via arc_end
MOVEL seam_end
WELD OFF
WELD JOIN extension_plate workpiece
PAUSE 0.2
GRAB workpiece
MOVEL carry_end
RELEASE workpiece
